How to write your questions

Number each question and mark the correct choice with an asterisk. Text, JSON and CSV are accepted. Multiple-choice, multiple answers, true/false, short answer, and essay questions are supported.

# Part I. Multiple Choice
Choose the best answer.

1. Which planet is closest to the Sun? [2]
A. Venus
B. Mercury *
C. Earth

2. Select the prime numbers. [3] (multi)
A. Two *
B. Three *
C. Four

# Part II. Short Answer
3. Name the chemical symbol for gold. (short)
Ans: Au | gold

# Part III. Essay
4. Explain your reasoning. // [10]
Sample JSON for questions

Copy this example into the exam text box below or save it as a .json file to upload. Replace the sample questions and answers, then select Preview pasted questions. For choice questions, answer text must match a choice. Essays are graded manually. Review part timing and locking in the editor before saving.

{
  "title": "Sample Exam",
  "sections": [
    {
      "title": "Part I. Multiple Choice",
      "instructions": "Choose the best answer.",
      "questions": [
        {
          "kind": "mcq",
          "prompt": "Which planet is closest to the Sun?",
          "choices": ["Venus", "Mercury", "Earth"],
          "answer": "Mercury",
          "points": 1
        },
        {
          "kind": "multiselect",
          "prompt": "Select all prime numbers.",
          "choices": ["2", "3", "4"],
          "answer": ["2", "3"],
          "points": 2
        },
        {
          "kind": "truefalse",
          "prompt": "The Earth orbits the Sun.",
          "answer": "True",
          "points": 1
        }
      ]
    },
    {
      "title": "Part II. Written Answers",
      "instructions": "Answer each question.",
      "questions": [
        {
          "kind": "short",
          "prompt": "What is the chemical symbol for gold?",
          "answer": ["Au", "gold"],
          "points": 1
        },
        {
          "kind": "essay",
          "prompt": "Explain why the sky appears blue.",
          "answer": null,
          "points": 5
        }
      ]
    }
  ]
}
